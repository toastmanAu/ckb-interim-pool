## Bugs found and fixed during the session

1. **Block submission nonce byte order (CRITICAL, consensus)**: the node
   serializes the header nonce as a u128 value in little-endian; miners
   hash the raw bytes. The submitter sent the raw form → the node hashed
   a different value → `InvalidNonce` for a genuine network-target
   solution (hash 0x0000…10 ≈ 2^196.6 vs target 2^197.0 — independently
   verified). Fix: submit the byte-reversed nonce
   (`block-submitter.js`, pinned by LE(value)==raw tests). Latent in the
   upstream proxy; invisible under Dummy PoW (why the dev-chain drills
   never caught it).
2. **Share work_units used the network target** instead of the assigned
   vardiff target — inflated the hashrate estimate ~15× (the "20 PH/s"
   from one miner) and would have corrupted PPLNS fairness. Fixed in
   share-validator.js; the 62.3 vs 66 TH/s agreement validates it.
3. **Integration tests shared the session database** and truncated live
   data twice. Fixed: dedicated `pooltest_ci` database created by
   pg-test.sh; tests are isolated from live sessions.
